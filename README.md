# Undead Siege — playable build

Static web build of **Undead Siege**, Map 01 "Kestrel Field" (map + world pass, no zombies yet).

Play: https://dustieyyy.github.io/undead-siege-play/

Built from the private source repo, branch `kestrel-field` @ 17f7663. This repo contains only the static game files.

Controls: WASD move, mouse look, Shift sprint, left click fire, right click aim, R reload, hold F to buy doors / flip power.
Debug: P +1000 points, [ ] teleport between areas, G show spawn zones, K toggle power, F3 stats.
Options: `?quality=low|medium|high`.

See CREDITS.md. All art is procedural/original; three.js is MIT.
