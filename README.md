# Undead Siege: playable build

Static web build of **Undead Siege**, Map 01 "Kestrel Field": zombies, barricades, rounds, 27 procedural WWII-era guns (12 wall-buys) and a working Supply Crate (950).

Play: https://dustieyyy.github.io/undead-siege-play/

Built from the private source repo, branch `main` @ cc5ccfd. This repo contains only the static game files.

Controls: WASD move, mouse look, Shift sprint, left click fire, hold right click to aim down sights, R reload, Q / mouse wheel / 1-2 swap weapon, hold F to buy doors / wall guns / ammo / open the Supply Crate and take its weapon, rebuild barricades, flip power. Touch: FIRE, AIM, RELOAD, USE, SWAP buttons.
Debug: P +1000 points, N skip round, J god mode, [ ] teleport, G spawn zones, K power, F3 stats.
Options: `?quality=low|medium|high`, `?round=N`, `?nozombies`, `?god`.

Credits: audio generated with ElevenLabs (elevenlabs.io), free tier, attribution required, non-commercial. The zombie model was made with Higgsfield/Meshy. three.js is MIT. See CREDITS.md.
