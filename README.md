# Undead Siege: playable build

Static web build of **Undead Siege**, Map 01 "Kestrel Field": zombies, barricades and rounds.

Play: https://dustieyyy.github.io/undead-siege-play/

Built from the private source repo, branch `kestrel-field` @ 5678807. This repo contains only the static game files.

Controls: WASD move, mouse look, Shift sprint, left click fire, right click aim, R reload, hold F to buy doors / rebuild barricades / flip power.
Debug: P +1000 points, N skip round, J god mode, [ ] teleport, G spawn zones, K power, F3 stats.
Options: `?quality=low|medium|high`, `?round=N`, `?nozombies`, `?god`.

Credits: audio generated with ElevenLabs (elevenlabs.io), free tier, attribution required, non-commercial. The zombie model was made with Higgsfield/Meshy. three.js is MIT. See CREDITS.md.
